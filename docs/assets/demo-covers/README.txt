MiniMax Music 3 demo covers
=============================

This folder contains the web cover images used by docs/index.html.

The authoritative expected filenames come from `docs/demo-tracks.js`; do not maintain a second hard-coded list in Python. For a lightweight GitHub repository, 960x960 progressive JPEGs at roughly quality 86 are sufficient.

If a cover is missing, the page falls back gracefully instead of displaying a broken image.

You can prepare all referenced covers with:

  python scripts/prepare_demo_covers.py --source "D:/path/to/generated/artwork"
