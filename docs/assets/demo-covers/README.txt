MiniMax Music 3 demo covers
=============================

Place the generated cover JPGs in this folder. The demo page already expects the
exact filenames listed below. For a lightweight GitHub repository, web-optimized
960x960 JPEGs at about 80-88 quality are sufficient.

If a cover is missing, the page shows a clean title placeholder instead of a broken image.

- Beyond the Known - The Long Resonance.jpg
