ComfyUI · MiniMax Music 3 · Open-source workflow

Generated music, from a simple idea to a finished demo.

These tracks were generated with the production workflow now published as the MiniMax Music Production Toolkit for ComfyUI. The workflow turns simple style prompts into structured MiniMax Music 3 captions, lyrics where needed, titles and cover concepts, then handles artwork, metadata and the final audio-processing chain.

GitHub repository SoundCloud playlist
Shared production settings for these demos: MiniMax Music 3 · up to 300 s · 40 sampling steps · CFG 1.7 · Euler / simple · PRE 12 kHz → FlashSR hybrid → gentle HF repair → POST 19 kHz · 44.1 kHz release preparation targeting −14 LUFS / −1 dBTP. Track-specific seeds, prompts and musical metadata are available under “Generation details”.
Audio is streamed from SoundCloud. Cover images can be stored in docs/assets/demo-covers/. Edit docs/demo-tracks.js only when you want to add, replace or update SoundCloud track/playlist URLs.
