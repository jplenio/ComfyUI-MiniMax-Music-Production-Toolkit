ComfyUI · MiniMax Music 3 · YuE2 Cover · Open-source workflow

Generated music, and covers of your own tracks.

Tracks created with the open-source Music Production Toolkit for ComfyUI: simple style prompts become structured captions, lyrics where needed, titles and cover concepts — then artwork, metadata and the final audio-processing chain. The second category shows cover versions: an original track, its score read straight out of the audio, and the covers made from it.

GitHub repository SoundCloud playlist
Shared production settings: MiniMax Music 3 · up to 300 s · 40 steps · CFG 1.7 · Euler / simple · PRE 12 kHz → FlashSR hybrid → gentle HF repair → POST 19 kHz · 44.1 kHz release targeting −14 LUFS / −1 dBTP. Track-specific seeds, prompts and musical metadata are under “Generation details”.
Cover songs: each original track was read by SheetSage2 into a score, and YuE2 then rendered a new version in a chosen style. Tempo and length below are measured from the original audio; the cover settings are the ones the run recorded. SoundCloud links appear as soon as a track is uploaded.
Audio is streamed from SoundCloud. Cover images can be stored in docs/assets/demo-covers/. Edit docs/demo-tracks.js only when you want to add, replace or update SoundCloud track/playlist URLs.
