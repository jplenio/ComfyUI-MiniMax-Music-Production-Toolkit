Tracks created with the open-source MiniMax Music Production Toolkit for ComfyUI: simple style prompts become structured MiniMax Music 3 captions, lyrics where needed, titles and cover concepts — then artwork, metadata and the final audio-processing chain. Press play and browse.

Shared production settings: MiniMax Music 3 · up to 300 s · 40 steps · CFG 1.7 · Euler / simple · PRE 12 kHz → FlashSR hybrid → gentle HF repair → POST 19 kHz · 44.1 kHz release targeting −14 LUFS / −1 dBTP. Track-specific seeds, prompts and musical metadata are under “Generation details”.
Audio is streamed from SoundCloud. Cover images can be stored in docs/assets/demo-covers/. Edit docs/demo-tracks.js only when you want to add, replace or update SoundCloud track/playlist URLs.
