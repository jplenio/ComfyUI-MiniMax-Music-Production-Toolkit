# Archived YuE2 system prompts

These twelve files are byte-for-byte copies of the prompts before the
section-synchronized arrangement revision following version 2.6.0.

Active versions are in `../system/yue2/`. This archive sits outside the active
system-prompt library so model selection continues to use the revised versions.
To compare an old prompt, paste its text into a manual system prompt or select
this folder as an external system-prompt directory.

The archived prompts intentionally retain the old short-Style and short
instrumental-map instructions for comparison; they are not the current defaults.
