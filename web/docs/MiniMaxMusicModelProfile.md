# Song model

Select MiniMax Music 3, YuE2 or YuE2 Cover before creating the song request. Connect
`profile_json` to Structured Song Prompt, the parser, Music settings, Generate
song and Prompt Report. The supplied Yue2 workflow contains these connections.

The profile describes the prompt family and settings policy; it does not load
weights. It changes the actual generator only in a workflow using Generate song.
The classic MiniMax workflow remains fixed to MiniMax.

YuE2's context is shared with ABC and music; the displayed text budget is a
toolkit estimate, not an independently measured model text limit.
