# Audio examples

Do not store a large catalog of MP3 examples in the normal Git repository. Git history is a poor distribution mechanism for hundreds of megabytes of generated audio.

Recommended public setup:

1. Publish full listening examples on a streaming/audio platform such as SoundCloud.
2. Organize them into a small number of genre playlists.
3. Link those playlists from the GitHub README.
4. Optionally create a GitHub Pages listening page that embeds the streaming players.
5. If useful, attach a **small curated sample pack** to a GitHub Release for users who want downloadable comparison files.

A good structure is one "Best Examples" playlist plus genre-specific playlists. Keep the repository itself focused on code, workflows, prompts and documentation.
